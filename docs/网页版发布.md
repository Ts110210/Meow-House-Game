# 网页版发布（给 iPhone 和在中国大陆的朋友用）

每次推送到 main，GitHub Actions 打完 APK 之后，会把同一份网页版自动发布到两个地方：

| 发布到哪 | 网址 | 适合谁 | 要先做的一次性设置 |
|---|---|---|---|
| GitHub Pages | `https://ts110210.github.io/Meow-House-Game/` | 国外、能上 GitHub 的人 | 下面第 1 步 |
| Cloudflare Pages | `https://meow-house.pages.dev`（名字被别人占了的话，Cloudflare 会自动加一串字母，以控制台里显示的为准） | 在中国大陆的朋友（比 GitHub 好打开一些，但不同地区、不同网络不一定都稳定，要请朋友实际试试） | 下面第 2 步 |

两个都没设置也没关系，只是跳过发布，APK 照常打包。

## 1. 打开 GitHub Pages

1. 打开仓库页面 → **Settings** → 左边的 **Pages**。
2. **Build and deployment** 下面的 **Source** 选 **GitHub Actions**。
3. 到 **Actions** 页面，点最近一次的运行右上角的 **Re-run all jobs**（或者等下次推送）。

注意：仓库是私有的话，免费账号用不了 GitHub Pages，要么把仓库改成公开，要么只用 Cloudflare。

## 2. 接上 Cloudflare Pages

1. 到 <https://dash.cloudflare.com> 注册一个免费账号（用邮箱就行）。
2. **拿账号编号（Account ID）**：登录后在首页点进 **Workers & Pages**，右边栏就有 **Account ID**，点一下复制。
3. **做一把钥匙（API Token）**：右上角头像 → **My Profile** → **API Tokens** → **Create Token** →
   最下面 **Create Custom Token** → 名字随便写（比如 meow-house）→ **Permissions** 选 **Account** · **Cloudflare Pages** · **Edit** → 一路继续 → **Create Token**，复制出来（只显示一次）。
4. **填到 GitHub**：仓库 → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**，新建两个：
   - `CLOUDFLARE_API_TOKEN` = 第 3 步的钥匙
   - `CLOUDFLARE_ACCOUNT_ID` = 第 2 步的账号编号
5. 到 **Actions** 页面，最近一次运行点 **Re-run all jobs**。跑完之后在 Cloudflare 的 **Workers & Pages** 里能看到 meow-house 这个项目和它的网址。

## 3. 朋友在 iPhone 上怎么玩

1. 用 **Safari** 打开上面的网址（微信里打开的话，点右上角「…」→「在浏览器中打开」）。
2. 点底部的分享按钮 → **添加到主屏幕**。桌面上会出现「喵屋」的图标，以后从图标打开是全屏的，和 App 差不多。

## 要知道的

- **存档跟着网址走**：GitHub 和 Cloudflare 的两个网址是两份不同的存档；在 Safari 里清除网站数据，存档也会没。重要的存档用游戏里的「存档：导出 / 导入」备份。
- **网页版没有的**：小米背屏（只有安卓 App 有）、准时的通知提醒（iPhone 网页上受限制）。
- **更新**：每次推送自动更新。朋友打开时如果还是旧的，关掉重新打开一次。
