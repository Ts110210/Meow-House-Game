# 设计取舍：为什么这样做

这里记的是**和主人讨论过、定下来的决定，以及当时的原因**，方便接手的人知道哪些不是随手写的。
具体数值在 `src/config.ts`；功能现状在 `README.md`；只记结论、不记原因的规矩在 `CLAUDE.md`。
以后再定新的取舍，也写在这里（新的写在对应小节的最后，带上日期）。

## 整体方向

- **游戏要给人「打开的理由」**（2026-11-22）。主人发现自己都懒得打开游戏，讨论下来的原因是：打开之前想不出这次会看到什么新东西，猫一直在家里做差不多的事，小鱼干买完一轮就没用了。所以这一批优先做的是「离开时发生了故事，回来才知道」（日记、门口的礼物、老家人回来串门），其次才是「打开有事做」（小玩法），最后是「加深感情」（纪念册、亲密度）。
- **不做每周小目标**（2026-11-22）。主人觉得没必要，带一点不确定性的奖励已经由礼物、邻居、季节活动承担了。
- **背屏只当额外功能**（2026-11-22）。不是所有手机都有背屏；小米背屏到现在还没给第三方开放接口（第三方应用都是小米逐家适配的），所以游戏不能依赖它。现在只保留游戏里的背屏预览，等小米开放了再接。调研在 `docs/背屏调研.md`。
- **自己当开发者，体验会比新玩家淡**。判断「好不好玩」时打个折扣，最好请两三个朋友试玩一周，看他们第几天不再打开、最后一次打开做了什么。

## 日记和礼物

- **日记一天一页、全家共用，不是每只猫各写一篇**。猫多了以后每只一篇会太长、也没人看完。所以每页最多 3 只当主角（每只 3 句），其他各一句，好几天没当主角的猫优先，保证一周里每只都能写到。
- **只留 30 天，喜欢的可以收藏（最多 50 页）**。主人问过「上限在哪里、多只猫怎么约束」。日记是纯文字，一页几百字节，30 天加 50 页收藏一共几十 KB，不会占空间；收藏上限是为了不让存档无限长大。
- **按真实发生的事写，不是随机文案**。随机文案很快会被看穿；从真实的事里挑（吃了什么、去了哪、谁来串门），玩家会觉得「它真的在过日子」。离开时的事是按经过的时段和天气补的，所以早上不会写「看星星」。
- **礼物：普通的只进图鉴，稀有的是能摆的装饰（主人选的「1 + 2」）**。主人问过「展示这些小东西是不是又要一件新家具」。为了不加新家具、也不加新的摆放规则，普通礼物只放进「猫的宝贝」图鉴；只有 3 件稀有的变成装饰，用现有的装饰系统摆。
- **礼物要离开 4 小时以上才有，一次最多 2 件，放 3 天不捡会被叼走**。这样「离开久一点再回来」才有意义，又不会每次一打开门口就堆满。

## 小玩法

- **可玩可不玩**（2026-11-22）。主人担心「有时候我只想加数值、不想玩，就浪费时间」。所以原来的「玩耍」按钮保留（一点就加心情），小玩法是旁边多一个「陪它玩」；捞鱼也有「让它自己去捞」——不用玩，猫自己去鱼塘守 1 小时，带回来的少一点。
- **逗猫棒小玩法要先买逗猫棒**（2026-11-23，主人选的）。没买也能玩的话，买逗猫棒只剩「玩耍多加点心情」，买的意义太弱。原来的「玩耍」按钮不受影响，没买时是空手逗。
- **小玩法的规则要画在画面上，不靠猜**（2026-11-23）。主人玩的时候不明白「太慢没反应、太快抓不到」是怎么判的，所以加了速度条（慢 / 刚好 / 快）、猫头上的话、准备扑时的「！」、扑空的原因，奖励写在下面。
- **捞鱼被鱼苗限制，不被天数限制**（2026-11-23，主人定的）。鱼塘里看不到鱼、捞鱼时却凭空冒出来，很出戏；所以鱼塘 3 个位置 = 3 批鱼，一局（或让它去的一批）捞走一批，没放鱼苗就不能捞。一条没捞到不算，不然一失手鱼苗就白放了。长大的那批给得比直接收获（18）多一点（陪它捞最多 24），让玩的人有赚头；让它去和直接收获差不多（15–18），图的是看它去捞、日记里有一笔。
- **让它去捞：主人自己选几批、走到了才计时**（2026-11-23，主人定的）。原来守 1 小时太久，猫一直不能互动；现在 1 批 2 分钟、2 批 4 分钟、3 批 5 分钟，记住上次选的。猫先放下手上的事走过去，到了才开始算，不然在屋顶上的猫还没走到就「捞完了」。游戏没开着时走不到，最多等 3 分钟就当它到了。下雨天鱼塘去不了，半路下雨按守了多久算捞完几批。
- **玩小玩法时房间里那只猫也跟着**（2026-11-23）。面板外面还看得到房间，猫在后面自己跑去窗台很违和：逗猫棒时它在原地陪玩，陪它捞时它在鱼塘边捞，关了面板才去做别的。别的猫照常活动。
- **饭碗里的粮单独一张图、程序裁着变少**（2026-11-23）。主人要碗有满有空、吃的时候一点点变空；分开画满碗、半碗、空碗要好几张，还要乘上每个皮肤；单独一层粮、从上往下裁，碗换皮肤也不用重画。只是画面，不进存档（重开游戏是空碗）。
- **客人看时间和天气**（2026-11-23，主人同意的）：深夜（22–7 点）和下雨天邻居猫、访客都不来，名额留到天亮、雨停；邻居猫在的时候下起雨就先回家。自家猫下雨会往屋里跑，客人却在雨里待着很怪。
- **每一项单独出安装包**：Actions 新推送会取消还没跑完的旧构建（`cancel-in-progress`），所以一项一项推的时候要等上一次跑完再推，不然中间的 build 号没有安装包。
- **收入：基础调高 + 猫多靠出门多赚**（2026-11-23，主人同意）。养成是长线，皮肤不降价；但猫多了光喂饭就花光，所以签到和每日任务调到每天 250–350 起步（不管养几只都有）。猫越多能赚越多，但要它们出门：每多一只同行，行李箱多装几件货（不另开打工系统）。
- **「想要」气泡只用已有的东西**（2026-11-23，主人定的）：不加新动画、新道具，气泡跟着数值冒，点了就做已有的喂、洗、摸、玩；以前只能等它自己去的玩球、抓猫抓板，点了它就去（算一次陪玩）。饿了点了不直接喂，打开宠物面板让主人挑吃的（主人选的）。冒气泡时把「饿 / 脏 / 闷」小牌子收起来，不然头上两样东西说同一件事。
- **挂在已有的东西上，不另开系统**。主人说过不知道小玩法怎么融进现有玩法：逗猫棒接在「玩耍」上，捞鱼接在院子的鱼塘上，用的都是猫已有的动作（跳跃、捞鱼、端坐），捞到的鱼直接是小鱼干（和货币名字对上）。
- **捞鱼做难了一点，奖励压低了**。替身环境里乱点 40 下能捞 16 条，太容易，所以缩小了爪子、拍完要等一下才能再拍；奖励改成一条 1 小鱼干、一局最多 8、每天 3 局，免得小玩法收入超过正常收入太多（经济平衡还没正式调，见 README 待办）。

## 纪念册和亲密度

- **纪念册只存「发生了什么」，不存图片**。主人问过「猫越来越多，存储怎么办」。每张只存时间、季节、白天晚上、那时候多大（约 200 字节），看的时候用房间背景、家具和猫的动作帧现画——换了正式素材，旧照片也自动变成新画风。每只猫 9 张，就算养很多只也不到 100 KB。照片按猫**当时**的大小画，幼年拍的就是小猫。
- **亲密度只涨不掉**。不想用「很久没来就扣分」惩罚玩家；很久没来时猫会闹一会儿脾气（原来就有），但不扣亲密度。每天每只最多涨 12，免得一天刷满。
- **在你上次离开的地方迎接，不是在门口**（主人改的）。所以打开游戏时镜头回到上次看着的地方，最亲你的那只已经在那里等着。
- **迎接从「所有猫都来」改成「亲密度够的才来」**，让亲密度有用处。为了不让老存档里的猫突然不迎接了，老存档里的猫亲密度从 20（「熟悉」，刚好会迎接）开始，新领养的从 0 开始。

## 长大的意义

- **体型和大部分玩法都挂钩**（2026-11-22）。主人说「不然体型成长跟游戏大部分内容都不相关」。
- **幼年自己出门只到近处**。主人举的例子：在马来西亚，幼年只能去本地和新加坡这种近处，长大了才没有限制。带的便当再好也只是走得久，不会走远。
- **成年的意义：能带孩子见世面**。成年猫和幼年猫一起出门，幼年的限制就取消了；成年同行时稀有纪念品的几率更高；在家会主动给幼年舔毛。以后加更远的地区（日本、澳洲等）时，可以只让成年猫去。
- **幼年不上屋顶、不上猫爬架顶层**，看得出它还小。

## 送养和走失

- **送养是温和的，不是删除**。猫搬去邻居那边住，以后会回来串门、搬去远方的会寄信，纪念册和日记都留着。
- **有冷却、有上限、没有奖励**（主人提的）。主人担心「我直接送养 50 只猫，让 NPC 全是自己曾经的猫」。所以：只有成年猫能送养、确认两次、两次至少隔 7 天、会回来串门的最多 3 只（更早的搬去远方，只寄信）、串门的老家人最多占串门的三分之一、送养不给任何奖励（免得变成刷猫）。
- **走失 7 天没找回的猫会被好心人收养**。原来走失的猫会一直占着位置，玩家没办法。现在会空出位置，之后和送养的一样偶尔回来。

## 光影

- **光都从后面照来，影子往前倒**（2026-11-22，主人看真机截图后提的）。原来窗户光是从后墙往前照，影子却往后墙上投，看着很违和。现在太阳、窗户、灯的影子都往前（画面下方）倒在地上。
- **下雨天屋里不跟着外面一起暗；灯白天下雨也开**（主人提的）。原来非晴天屋里很暗，买了灯也要等到晚上才亮，白天看屋里很难受。「超高」里每个房间还加了一盏看不见灯具的固定顶光，白天一直有一点补光。
- **屋里的投影只在「超高」里有**。正面视角下，屋里的影子跟着太阳转会很怪，所以「高」和「简单」屋里只有脚下的接触阴影；主人想要像泰拉瑞亚那样的光照面积和多光源投影，放在「超高」这一档。
- **默认「简单」**（主人选的）。先保性能，想要好看再调高。
- **光影全是程序算的，素材里不画光影**。这样换素材、换时间、换天气都不用准备多套图；代价是素材必须按「白天、光线均匀」画，不然两层光影叠在一起。

## 美术和素材

- **同一个房间的家具放在一张图里一起生成，再用「整张切图」切开**（主人的出图方法）。单独一张张生成太慢，而且每张画风会漂；一起画的配色、笔触、描边自然一致。出图计划在 `docs/出图清单.md`。
- **跳跃是「原地跳」，高度只靠程序的弧线**（2026-11-21，主人定的）。如果帧里也带高度，会和程序的弧线叠加，跳得过高或在空中顿一下；爬梯子借用跳跃行时也会上下跳。
- **体型：成年猫原来太大**（2026-11-22，主人看了以后改的）。青年的大小最合适，所以成年 = 原来青年的 1.2 倍、幼年 = 原来幼年的 1.1 倍，再整体大 5%。改的是基准大小和阶段比例，每只猫自己的大小没动，所以旧存档不用迁移。
- **别人的素材包只在手机上导入，不进仓库**（2026-11-23）。仓库是公开的，很多免费素材（itch.io 上大多数）允许用在游戏里但不允许把原图再分发；放进 `public/assets/` 推上去就等于再分发。所以加了「导入素材包」：zip 存在手机本地、能一键清掉。确认是 CC0 或授权允许再分发的才放进仓库，CC-BY 的要另写署名。
- **代码画的占位图一直保留**：有图用图、没图用占位，删掉图就退回去。这样换素材可以一件件来，不怕换坏。
- **整张背景可以出高分辨率**（2026-11-20）。手机上放大后 3456 宽的图很糊；程序按 3456×1440 摆、切成每块不超过 4096 像素的小块（很多手机的贴图上限），这样换不同大小的图都不用重新对齐。
