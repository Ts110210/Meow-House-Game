# 安卓打包、安装步骤（给第一次做的人）

目标：在电脑上把游戏打包成 APK，装到手机上。全程不用写代码。
第一次大约要 1–2 小时，大部分时间在等下载；之后每次改完重新打包只要几分钟。

> 这份工程我没有条件在真机上验证（我这边没有安卓编译环境）。
> 步骤是按 Capacitor 8 的官方要求写的，如果某一步报错，把报错的**第一段红字**发给我。

## 一、装两个软件（只做一次）

### 1. Node.js（22 或更新）

1. 打开 https://nodejs.org ，下载 **LTS** 版本，一路「下一步」装完。
2. 检查：打开终端（Windows：开始菜单搜「PowerShell」；Mac：搜「终端」），输入

   ```
   node -v
   ```

   显示 `v22.x.x` 或更大的数字就对了。Capacitor 8 要求 22 以上，低了会报错。

### 2. Android Studio（2025.2.1 “Otter” 或更新）

1. 打开 https://developer.android.com/studio ，下载并安装。
2. 第一次打开会有安装向导，全部选默认（Standard），它会自动下载 Android SDK，等它下完。
3. 不用另外装 Java，Android Studio 自带。

## 二、准备工程（只做一次）

1. 把我发的源代码压缩包解压到一个**路径里没有中文和空格**的文件夹，比如 `D:\pet-game` 或 `~/pet-game`。
2. 在终端里进入这个文件夹：

   ```
   cd D:\pet-game
   ```

3. 安装依赖（要联网，几分钟）：

   ```
   npm install
   ```

## 三、打包并打开 Android Studio（每次改完代码都做）

在同一个终端里输入：

```
npm run android
```

它会依次做三件事：把游戏打包到 `dist/` → 复制进安卓工程 → 打开 Android Studio。

**第一次打开时**，Android Studio 右下角会显示 “Gradle sync” 的进度条，它在下载编译工具，
可能要 10–30 分钟，等它跑完、不再有进度条再继续。如果弹出提示问要不要升级 Gradle 插件
（AGP Upgrade Assistant），**选不升级**。

## 四、装到手机上

有两种办法，选一种。

### 办法 A：数据线直接装（推荐，之后每次更新最快）

**先在手机上打开开发者选项**（小米 / HyperOS，菜单名字可能略有不同）：

1. 设置 → 我的设备 → 全部参数与信息 → 连续点 **OS 版本** 7 次，提示「已处于开发者模式」。
2. 设置 → 更多设置 → 开发者选项，打开这三项：
   - **USB 调试**
   - **USB 安装**（小米要求插着 SIM 卡并登录小米账号才能打开）
   - **USB 调试（安全设置）**
3. 用数据线连上电脑。手机弹出「允许 USB 调试吗？」→ 勾选「始终允许」→ 确定。
   如果手机问 USB 用途，选「传输文件」。

**然后在 Android Studio 里：**

1. 顶部工具栏中间的设备下拉框里应该出现你的手机型号。
2. 点旁边绿色的三角形 **Run ▶**。
3. 手机上可能弹出「是否安装」→ 点「继续安装」。装完会自动打开游戏。

### 办法 B：生成 APK 文件，自己传到手机上装

1. Android Studio 菜单：**Build → Generate App Bundles or APKs → Generate APKs**
   （旧一点的版本叫 Build → Build Bundle(s) / APK(s) → Build APK(s)）。
2. 完成后右下角弹出提示，点里面的 **locate**，就能看到文件：

   ```
   android/app/build/outputs/apk/debug/app-debug.apk
   ```

3. 把这个文件发到手机上（微信文件传输、数据线拷贝都行），在手机上点开安装。
   第一次会提示「不允许安装未知来源应用」，按提示去设置里给文件管理器或微信打开这个权限。

这是调试版 APK，自己装着玩完全够用；要上架应用商店才需要另外做签名。

## 五、让提醒能正常弹出来（小米手机很重要）

游戏里的「饿了」「回家了」提醒是手机本地的定时通知。小米系统默认会限制后台，需要手动放行：

1. 第一次打开游戏，到 **菜单 → 提醒** 点一下（先关再开），系统会问是否允许通知 → 允许。
2. 设置 → 应用设置 → 应用管理 → 喵屋：
   - **自启动**：打开
   - **省电策略**：选「无限制」
   - **通知管理**：确认是允许的
3. 提醒是在你**离开游戏的时候**安排的，时间是按当时的状态算出来的，所以：
   - 刚喂饱就退出，「饿了」的提醒大约在 20 多个小时以后；
   - 派宠物出门后退出，到它回家的时间会提醒。
   - 想快速验证：派一只带猫粮出门（30 分钟），退到桌面等着。

## 六、以后更新

改了代码或换了素材之后：

```
npm run android
```

然后在 Android Studio 里再点一次 **Run ▶**（或重新生成 APK）。存档不会丢：覆盖安装会保留数据。
**不要先卸载再装**，卸载会清掉存档。保险起见，更新前可以在游戏里
「开发者面板 → 存档：导出 / 导入 → 复制存档文字」留一份。

## 七、常见问题

| 现象 | 原因和办法 |
| --- | --- |
| `npm run android` 报 `engines` 或 Node 版本太低 | Node 低于 22，重装 LTS 版 |
| Gradle sync 失败，提到 `invalid source release: 21` | Android Studio → Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK，选自带的 JDK 21（jbr-21） |
| 提示缺 `Android SDK Platform 36` | Android Studio → Tools → SDK Manager，勾上 Android 16（API 36）安装 |
| Gradle sync 一直卡着下载 | 网络问题。换个网络，或开着代理再点 File → Sync Project with Gradle Files |
| 设备下拉框里没有手机 | 换一根能传数据的线；手机上重新确认「允许 USB 调试」；开发者选项里三项都开着 |
| 安装时手机提示「安装被拦截」 | 开发者选项里的「USB 安装」没打开，或没登录小米账号 |
| App 打开是白屏 | 多半是没先打包网页。重新运行 `npm run android` |
| 顶部按钮被状态栏或挖孔挡住 | 截个图发我，我调一下安全区 |
| 想改应用名字或图标 | 名字在 `capacitor.config.ts` 和 `android/app/src/main/res/values/strings.xml`；图标在 Android Studio 里右键 `app` → New → Image Asset |

## 八、App 里和网页版不一样的地方

- **返回键**：有面板时关面板；在「调整点击区域 / 调整背景」里是退出调整；什么都没开时把 App 收到后台（不是退出）。
- **切到后台**：马上存档，并安排提醒；回到前台时取消还没弹的提醒，并补算离开期间的变化。
- **存档**：除了 WebView 自己的存储，每次存档还会往系统偏好设置里多写一份，前者丢了会自动拿回来。
- **下载按钮**（精灵图、存档文件）在 App 里可能不起作用，存档请用「复制存档文字」。
- **背屏**：现在只有游戏里的背屏预览，还没有真正显示到背屏上，见 `docs/背屏调研.md`。
