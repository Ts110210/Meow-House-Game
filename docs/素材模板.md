# 素材模板（出图照这个来）

所有素材都是「有图用图，没图用代码画的占位图」。把文件放进 `public/assets/` 对应的位置、用下面的文件名，重新打包就生效；
也可以在开发者面板 →「素材替换」里直接上传试效果。每次加新动作、新物品，都只更新这一份文件。

通用要求：PNG、透明背景（房间背景和明信片背景除外）、彩铅手绘风、描边深棕色。

## 1. 宠物精灵图 `pets/<毛色>.png`

- 一张图 1024 × 2048，分成 4 列 × 8 行，每格 256 × 256
- 每格里：宠物**面朝右**，脚底踩在格子高度的 90% 处（y ≈ 230），左右居中
- 每行一个动作，从左到右是这个动作的 4 帧：

| 行 | 动作 | 用在哪 | 缺了用什么顶替 |
|---|---|---|---|
| 1 | idle 待机 | 平时站着、明信片 | 必须有 |
| 2 | walk 走路 | 走动、追球 | idle |
| 3 | eat 吃 | 饭碗旁低头吃 | idle |
| 4 | sleep 睡 | 夜里、虚弱、明信片 | idle |
| 5 | happy 开心 | 被摸、明信片 | idle |
| 6 | play 玩 | 逗猫棒、猫抓板、扑球 | happy |
| 7 | bath 洗澡 | 泡在浴缸里（只露出遮挡线以上） | idle |
| 8 | lick 舔毛 | 平时偶尔、明信片 | idle |

- 毛色文件名：orange、grey、cream、black、tabby（狸花）、calico（三花）、tortie（玳瑁）、cow（奶牛）、siamese（暹罗）、persian（波斯）
- NPC 狸花猫现在只有代码画的占位图，还没有接图片；要出图时告诉我，我加上接口
- 头像（可选）：`avatars/<毛色>.png`，正方形，建议 256 × 256

以后要加的专属动作（现在都用 play 顶替）：抓猫抓板、带球跑、扑逗猫棒。加的时候在表里接着往下加行，图片变成 1024 × (256 × 行数)。

## 2. 家具和物品 `objects/<名字>.png`

- 底边贴地：图片最下面一行像素就是物品接触地板的位置
- 尺寸不限，游戏按「高度」缩放；宽高比按图片自己的来

| 文件名 | 物品 | 特别的要求 |
|---|---|---|
| bowl | 饭碗 | 左右各留空，最多 4 只围着吃 |
| tub | 浴缸 | **遮挡线**：从顶部往下 20% 处是浴缸边沿，线以下会盖在宠物前面。边沿位置变了，改 `assets.config.ts` 里 tub 的 `frontFrom` |
| bed | 床 | |
| scratcher | 猫抓板 | 宠物站在左侧抓 |
| ball | 玩具球 | 会被带着跑，画成正圆 |
| lamp | 落地灯 | **发光点**：灯罩中心。位置写在 `light: [横向比例, 纵向比例]` |
| feeder、door、cabinet、album、pond | 喂食机、门、收藏柜、相册墙、鱼塘 | |

每件物品的位置、高度、站位都可以在开发者面板里打开「显示范围框」对着看：
蓝框 = 图片范围（也是点击范围），绿点 = 宠物站位，橙线 = 遮挡线，黄点 = 发光点。

## 3. 房间背景 `rooms/…`

见 `public/assets/README.md`（整条长图或分区图都可以，用「调整背景」模式对齐地板线）。
注意：如果浴缸、床这些已经画在背景里，物品图就不用出了——但那样浴缸没有「前面一层」，宠物会显示在浴缸前面。想要泡在里面的效果，浴缸要单独出图。

## 4. 明信片背景 `postcards/<地点>.png`

- 600 × 400（或同比例更大），不透明，画面下方 1/3 留出宠物能待的地面
- 地点文件名：singapore、penang、langkawi、bangkok、chiangmai、bali、cameron、angkor、halong、borneo
- **落脚点**：宠物站在哪、能摆什么姿势，写在 `src/art/postcard.ts` 的 `CARD_SPOTS` 里（按地点类型分：city、sea、forest、rain、mountain）。
  每个点 = 脚底位置 x、y + 大小 + 允许的姿势；标了 water 的点只有带泳圈才会去。
  出了新背景后，打开「显示范围框」再看明信片，所有落脚点会标在图上，对着改数字。
- 行李道具（相机、泳圈、伞、雨靴、帐篷）现在是代码画在宠物身上的；以后要换成图片，再加一行模板。

## 6. 房间装饰 `decor/<名字>.png`

- 透明背景 PNG，底边贴着物件的最下面；游戏按「显示高度」缩放，宽高比按图片自己的来
- 清单和显示高度在 `src/config.ts` 的 `DECOR` 里，图片路径在 `src/assets.config.ts` 的 `decor` 里
- 三种摆法：`wall` 挂墙上（挂画、相框）、`floor` 铺地上（地毯，宠物踩在上面）、`stand` 摆地上（盆栽、书架、灯）
- 会发光的（小夜灯）在 `DECOR` 里写 `light: [横向比例, 纵向比例]`

| 文件名 | 物件 | 摆法 | 显示高度 |
|---|---|---|---|
| cushion | 靠垫 | stand | 46 |
| mat | 小圆垫 | floor | 40 |
| poster | 小鱼挂画 | wall | 80 |
| plant | 小盆栽 | stand | 90 |
| rug | 编织地毯 | floor | 64 |
| painting | 风景挂画 | wall | 120 |
| nightlight | 小夜灯 | stand | 70 |
| bigplant | 龟背竹 | stand | 210 |
| shelf | 小书架 | stand | 190 |
| globe、goldframe、trophy | 里程碑奖励：地球仪、金边相框、奖杯 | stand / wall / stand | 96 / 130 / 100 |

加一件新装饰：`DECOR` 加一行（名字、价格、高度、摆法）→ `assets.config.ts` 的 `decor` 加一行路径 → 放图片（没有图片时在 `src/art/decor.ts` 里画个占位图）。

## 7. 访客

现在用捏猫系统的配色当占位（`src/config.ts` 的 `VISITORS`，改 `look` 那一串就能换花色）。要出专属图时告诉我，我加上图片接口，格式和宠物精灵图一样。
