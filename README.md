# 喵屋 Meow House（v0.7.0）

养猫的手机小游戏：喂食、洗澡、陪玩，派它们出门旅行，收明信片和纪念品，布置房间。
TypeScript + PixiJS，用 Capacitor 打包成安卓 App。美术目前全部是代码画的彩铅风占位图，都可以换成图片。

- 网页预览版：https://claude.ai/artifact/LVbx5Ga666fJqhFytToquw
- 安卓安装包：每次推送到 main 都会自动打包，在 [Releases](https://github.com/Ts110210/Meow-House-Game/releases) 里下载最新的 `build-N`（覆盖安装，存档保留）
- 版本号：`0.大版本.小修` 写在 `src/config.ts` 和 `package.json`；安装包另有自动递增的 build 号
- 存档格式：第 6 版，旧存档打开时自动升级
- 网页版（iPhone 用 Safari 打开、添加到主屏幕）：发布和设置见 [`docs/网页版发布.md`](docs/网页版发布.md)
- 接着开发（包括交给另一个 AI 对话）：先读 [`CLAUDE.md`](CLAUDE.md)；出图照 [`docs/素材模板.md`](docs/素材模板.md)，背景整张图的构图参考 [`docs/构图底稿.png`](docs/构图底稿.png)

## 功能清单

**养宠物**
- 三项状态：饱食、心情、干净，随时间下降；离开游戏期间按真实时间补算
- 喂食（猫粮、鱼罐头、豪华便当）、洗澡、摸摸、玩耍；同一种照顾短时间内重复，效果递减
- 猫粮在饭碗吃（最多三只一起）；鱼罐头、豪华便当在厨房空地上吃，吃完留下空罐空盒；有自动喂食机时自己去出粮口吃，一次一只
- 成长：幼年 → 青年 → 成年；公猫、母猫（领养时可以选，也可以随缘）：成年公猫是最初设计的 85%–90%，母猫 80%–85%，每只领养时随机定，青年是自己成年的 2/3，幼年一半。邻居和访客也在这个范围里
- 新手保护：第一只宠物在幼年期饱食下降减半
- 最多 5 只；10 种内置毛色（橘猫、灰猫、奶白、黑猫、狸花、三花、玳瑁、奶牛、暹罗、波斯）
- 捏猫：自选花纹、颜色、眼睛、长短毛；可以从照片取色（只在本地算）；可以换自己的头像
- 性格 4 种：贪吃、黏人、爱干净、爱冒险，领养时随机或手选；性格会影响平时的行为（讨吃的、坐着看你、常舔毛、爱往外跑）
- 友情：一起出门、一起玩会增加；到 30 会互相舔毛、蹭头、挨着睡；成为好朋友后一起玩心情加倍、结伴出门更容易带回纪念品
- 对主人的反应：离开 10 分钟以上再打开会跑来迎接；离开一天以上，有一只会背对着你闹脾气，摸一下才好
- 虚弱太久会离家出走（不会死）；给门口的狸花猫一根猫条，它出去找 2 小时，两成找不到，带回来时状态很低

**房间和宠物的行为**
- 8 个区域：门口、厨房、客厅、浴室、卧室、收藏柜、阳台、院子；左右滑动或点底部按钮切换
- 房子上面还有一层屋顶（梯形，从门口一直盖到阳台，院子上面是天空）：点底部最后的「屋顶」切过去，或者在阳台点木梯子、确认后上去（在屋顶上点梯子顶端可以回阳台），落在右边的木梯子那里，在上面也能左右滑；镜头不跟着猫。屋顶跟着四季、昼夜、天气变
- 宠物自己走动（左右和前后都会走）、睡觉、舔毛、互相玩；和家具、装饰按脚底位置排前后
- 走到饭碗旁吃（最多四只围着）、泡进浴缸（两只一起）、原地被逗猫棒逗；位置满了在旁边等
- 自己抓猫抓板、带着球跑、追自动逗猫球；跳上床、沙发、窗台、阳台的椅子、橱柜台面、收藏柜顶、三层猫爬架（可以指定谁待哪一层）；钻纸箱、洗衣篮、隧道
- 鱼塘里有鱼时闲着会去岸边坐着看鱼（真捞是主人陪它捞或让它去捞）、扑蝴蝶、啃猫草；冬天围着暖炉；晴朗的夜里偶尔顺着阳台的木梯爬上屋顶看星星，有时就在屋顶上睡一觉（概率低，同时最多两只；天亮、下雨、饿了或被叫去喂饭就爬下来）
- 16 种动作，包括跳跃、打哈欠（睡前）、伸懒腰（睡醒）、端坐、给同伴舔毛、站起来讨要
- 天气：晴和雨（冬天是大雪），每 3 小时变一次；下雨时宠物不出门，趴在窗台上看雨
- 昼夜（白天、傍晚、夜晚）跟着真实时间；夜里保留暖色调，窗外有星空，灯有光晕
- 猫的日记：每天一页，全家共用；从当天真实发生的事里挑（吃饭、被摸、出门、回家、长大、邻居串门、拍到的瞬间、叼回来的礼物），你离开两小时以上再回来会补上你不在时它做的小事；按性格换写法；最多 3 只猫写得详细、其他各一句，轮流当主角；只留 30 天，收藏的页一直留着（最多 50 页）；菜单按钮有新日记时亮红点
- 长大的意义：幼年自己出门最远只到近处（新加坡、槟城、兰卡威），带一只成年猫一起就不限；有成年猫同行时稀有纪念品的几率 ×1.6；幼年爬不了梯子上屋顶、跳不上猫爬架顶层；成年猫和幼年猫都闲着时，大的常去给小的舔毛
- 送养：成年猫可以「为它找个新家」（宠物面板最下面，确认两次），搬去邻居那边住，空出位置，没有奖励；两次送养至少隔 7 天。会回来串门的「老家人」最多 3 只（更早的搬去远方，只偶尔寄信），老家人串门至少隔 2 天、打开游戏时 40% 几率、待 30–60 分钟，串门时能摸它、陪它玩。走失 7 天没找回的猫会被好心人收养，和送养的一样。纪念册和日记都留着，家庭成员里能看到「住在别处的家人」
- 亲密度（0–100，只涨不掉，每天每只最多涨 12）：照顾、陪玩、出门回来、它送你礼物都会涨。到 20「熟悉」你回来时它会跑过来迎接，到 50「亲近」迎接时会蹭你；家里最亲你的那只会在你上次离开时看着的地方等你（打开游戏从上次看着的地方开始）。老存档里的猫从 20 开始，新领养的从 0 开始
- 「第一次」纪念册：每只猫 9 个「第一次」（第一顿饭、第一次被摸、跳上猫爬架顶层、上屋顶、出远门回来、交到邻居朋友、长成青年、长成大猫、第一次主动蹭你），发生时拍一张照片（只存时间和当时的大小，按当时的样子现画），日记里也写一句
- 猫想要什么时头上冒一个能点的小气泡：饿了（点了打开宠物面板挑吃的）、脏了（直接洗）、闷了（家里有球、自动球、猫抓板就想玩那样，点了它跑去玩；没有就直接陪它玩）、很久没人摸（直接摸）。满足了亲密度额外加一点，隔一阵才会再冒；睡着、在屋顶、正忙时不冒
- 小玩法（可玩可不玩，原来的「玩耍」照旧一点就加心情）：宠物面板「陪它玩」（要先买逗猫棒，没买时按钮带锁、点了去商店），20 秒拖着逗猫棒晃：上面一条速度条，停在「刚好」它才追，太慢它发呆、太快它看花眼；它蹲下头上冒「！」时把逗猫棒放低停在它面前，扑中加心情，规则和奖励写在下面；鱼塘面板「陪它捞」，20 秒看准鱼影点一下，爪子拍下去捞鱼。捞的是鱼塘里放的鱼苗：没放鱼苗不能捞，一局捞一批（先捞长大的，鱼影大、给得多；没长大的鱼小难捞），捞到了这批就没了，一条没捞到鱼还在塘里；不按天限次数，有几批鱼就能捞几局。逗猫棒每天前 3 局有小鱼干奖励（一局最多 8）。不想玩可以「让它去」：选捞 1–3 批（2 / 4 / 5 分钟，记住上次选的），猫先放下手上的事走到鱼塘边，到了才开始计时，捞完带小鱼干回来，守着的那几批不能收获；下雨天去不了，半路下雨提前回来，没捞完的还在塘里。玩的时候房间里这只猫也跟着（原地陪玩、在鱼塘边捞）
- 猫叼回来的礼物：离开 4 小时以上再回来，在家的猫有几率在门口放一样小东西（一次最多 2 件，季节不同东西不同），点一下收进「猫的宝贝」图鉴；8% 是稀有的，收到后是一件能摆出来的装饰；放 3 天不捡会被叼走
- 光影跟着手机的真实时间平滑变（清晨、上午、中午、下午、黄昏、夜晚）：整体光色（清晨偏粉、黄昏偏橙、夜里偏蓝暗，下雨偏冷偏灰）；脚下的接触阴影；阳台、院子、屋顶上跟着太阳转的影子（早上往右拉长、中午短、傍晚往左拉长）；厨房和卧室窗户斜照进来的光。设置里「光影效果」分超高 / 高 / 简单 / 关，默认简单；开发者面板可以拖时间预览
- 光影效果「超高」（像泰拉瑞亚）：光照图让每个房间按离窗户、离灯的远近有亮有暗，墙和大家具会挡光；白天的窗户、夜里的每盏灯都单独让附近的家具和猫往背离光源的方向投影（几盏灯就几道影子，能落在后面的家具上）；家具朝光的一面亮、背光的一面暗；喂食机夜里有指示灯、鱼塘白天反光，暖炉火光、萤火虫罐、灯笼会闪
- 四季：默认游戏内循环（每季现实 7 天，从春天开始），也可以改成跟真实月份；主界面可以显示季节

**出门旅行**
- 带便当、行李、行商货物出门；便当越好能去越远的地方，行李影响去哪和明信片里的样子
- 东南亚 10 个地点；每趟路上寄回一张明信片，回家再带一张，都有一句日记
- 明信片：宠物的位置和姿势随机但站在地面上；按季节 × 时段有 12 种色调
- 纪念品：每地 2 件（一普通一稀有），不重复
- 相册上限 50 张，可以保存到手机相册、手动删除；满了由主人挑着删
- 相册墙挂 4 张、收藏柜摆 9 件，都可以自己选
- 图鉴：每个地点的变体 x/12、纪念品 x/20，7 档里程碑奖励

**访客和邻居**
- 访客：开始玩满一天之后（游戏时间）才会来，每天 0–2 个（狸花猫、邻居家的猫、快递猫），打开游戏时出现在门口，几小时没理会就走
- 三类事：送小礼物；用食物换稀有纪念品；托宠物送信到某个地点（派出门时可以选「顺路送信」，回来有谢礼）
- 常客：帮同一位访客 3 次送一款皮肤，7 次送一件商店买不到的装饰
- 邻居猫：麻薯、大黑、花卷，开始玩满一天之后（游戏时间）才会来，开着游戏时会来串门（麻薯从院子的栅栏进出；大黑和花卷从左边的屋檐过来、走过屋顶、顺着阳台的木梯下来，走的时候原路回去），和宠物玩、蹭饭；熟了之后宠物可以去它家玩 30 分钟，带回一句小见闻
- 邻居走时可能在院子里留下小鱼、小花或脚印纸条，点一下捡起来

**收集**
- 季节活动：每季在院子里捡三种小东西，集齐送当季限定的装饰
- 瞬间相册：游戏自己抓拍 12 种有趣的时刻（三只挤一张床、捞鱼、看星星……），可以保存到手机；最多 60 张，满了要自己删（和明信片一样）

**商店和经济**
- 小鱼干：每日签到、每日任务、鱼塘（鱼苗长大后收获）、行商卖货、访客、里程碑
- 第一次打开（新存档）：屏幕变暗，只亮出要点的东西，一步步带着做：欢迎 → 点猫 → 喂猫粮 → 摸摸 → 点顶部的「引导」按钮；做完界面就解锁，只出现一次
- 任务（顶部的「引导 / 任务」按钮）：新存档先走 10 步新手引导（摸、喂、洗、玩、签到、派出门、收明信片、买东西、挪装饰、上屋顶），每步领 10–20 小鱼干，共 140；全部领完后每天随机 3 个小任务，每个 15–25，三个都领完再 +30。每一项都有「去做」按钮带你过去。已经玩了一天以上的旧存档直接从每日任务开始
- 食物、行李、货物、鱼苗、猫条
- 家里的东西：自动喂食机、逗猫棒、猫抓板、玩具球、猫爬架、吊灯、床头灯、纸箱、洗衣篮、猫草盆、猫隧道、自动逗猫球、小暖炉
- 房间装饰：地毯、挂画、盆栽、靠垫、灯、书架等，在「布置房间」里摆放、拖动、收起来。摆放有规则：挂画只能挂在空墙上（不叠窗户、置物架、门、别的挂画，阳台院子没有墙），地上的东西脚底不能和家具、别的装饰叠，不能挡门前的路和猫的站位；院子不能摆，阳台只能摆盆栽、灯笼这类户外也合适的；放不下时框变红并说原因。读档时位置冲突的装饰会自动收起来。开局自带大地毯两块、中地毯三块、小圆垫、几幅挂画和三盆小盆栽（不算在购买上限里）
- 背景只有墙、地板和窗外的远景；窗户、置物架、镜子、毛巾架、挂钩、伞桶、阳台的椅子、院子的大树和栅栏、阳台和院子交界的收边（木条、矮木阶和草边，跟着季节换）都是单独的固定家具（能换皮肤，大树跟着季节换），窗外的天空和雨丝由程序画在窗玻璃后面
- 家具皮肤：每件家具和装饰有 5 款（原木、奶油、薄荷、莓果、夜蓝）；除了买，里程碑和常客也会送
- 房间风格：3 套整体背景（暖木小屋、海盐小屋、樱粉小屋）

**声音**
- 背景音乐、操作音效、4 种猫叫，三条通道分开，菜单里有两个音量滑块（目前全是代码合成的占位音）

**开发者模式**（菜单最下面的版本号连点 5 次）
- 时间倍速、跳过时间；把每只宠物直接设成幼年、青年或成年（看体型）
- 一键切换昼夜、四季和天气；叫邻居来、让三只邻居都变成朋友
- 素材替换：在页面里上传图片预览；调整点击区域；调整背景对齐；精灵图拼装；整张切图（一张白底图自动切成很多件、选文件名、窗户挖玻璃、预览、打包成 zip）；导入素材包（zip 按路径对上文件名自动换上，只存在手机上，可一键清空）

## 文件

| 文件 | 内容 |
| --- | --- |
| `src/assets.config.ts` | **所有素材路径**，以及每件物品的位置和大小。图片放进 `public/assets/`（文件名见里面的 README），缺的继续用占位图 |
| `src/config.ts` | **所有数值**：下降速度、保底线、价格、出门时间、目的地、纪念品、上传规范、季节、光线、家具皮肤和房间风格 |
| `src/sim.ts` | 游戏规则（状态、时间补算、成长、虚弱与离家出走、效果递减、出门、行商、鱼塘、签到、商店、季节和天气、皮肤、邻居、季节活动、瞬间），不碰画面 |
| `src/game.ts` | 存档、时间、精灵图的总管 |
| `src/scene.ts` | PixiJS 房间：9 个区域、镜头、前后遮挡、宠物自己的行为（走动、跳上家具、捞鱼、互动）、邻居猫、天气 |
| `src/ui.ts` | 所有面板，包括上传导入、背屏预览、开发者面板 |
| `src/sprites.ts` | 按上传规范读精灵图（默认宠物也走这里） |
| `src/art/` | 代码画的彩铅风占位图（房间、物品、装饰、默认宠物的 16 行动作、明信片、瞬间照片）。换上图片后对应的占位图自动不用 |
| `src/backscreen.ts`、`src/backscreenModes.ts` | 背屏画面（宠物、小剧场、时钟） |
| `src/save.ts` | 存档的版本、升级和修复 |
| `src/geo.ts` | 房间的几何（地板线、每个区域的范围）。有背景长图时跟着图片走 |
| `src/layout.ts` | 「调整点击区域」「调整背景」拖出来的结果：保存、还原、导出 |
| `src/assemble.ts` | 精灵图拼装：每个动作一张横排 4 帧的图 → 标准精灵图 |
| `src/sheetCut.ts` | 整张切图：按内容找出每一件、去白底、窗户挖玻璃、打 zip |
| `src/light.ts` | 跟着时间变的光影：几点 → 光色、太阳方向、影子形状、窗户光颜色（纯函数）；画在 `scene.ts` 的 `drawShade / drawShadows / drawWindowLight` |
| `src/assets.ts` | 素材加载：页面里上传的 → `public/assets/` 的文件 → 占位图 |
| `src/platform/` | 存档和通知的平台层。打包安卓时只换这里 |

## 打包成安卓 App

工程里已经带了 Capacitor 配置（`capacitor.config.ts`）和生成好的安卓工程（`android/`）。
给新手的完整步骤见 **`docs/安卓打包步骤.md`**。熟悉的话就是：

```bash
npm install
npm run android     # 打包网页 → 同步到 android/ → 打开 Android Studio
```

安卓 App 里多出来的功能都在 `src/platform/native.ts`：返回键、切到后台时存档、本地通知（饿了、快撑不住、回家）、存档多存一份到系统偏好设置。
真正接入小米背屏属于第二阶段，见 `docs/背屏调研.md`。

出图和换素材照 **`docs/素材模板.md`** 来：每件家具的文件名、大小、落脚点，以及 5 款皮肤和 3 套房间风格的文件名规则都在里面。
